
# GOOGLE-03 – Solución de ejercicios

Este repositorio contiene la solución de cinco problemas de programación de Google Code Jam, desarrollados en **Python**.

Los ejercicios resueltos son:

1. **d1000000:** Algoritmo voraz para construir la mayor escalera posible con dados.
2. **Moons and Umbrellas:** Programación dinámica para minimizar costos.
3. **Parenting Partnering Returns:** Asignación de actividades sin conflictos de horarios.
4. **Chain Reactions:** Optimización de valores mediante árboles y programación dinámica.
5. **Bathroom Stalls:** Simulación optimizada de la distribución de espacios.

Cada ejercicio cuenta con su código fuente (`solucion.py`), archivo de entrada (`Entrada.txt`) y resultados de ejecución (`salida.txt`).

**Lenguaje:** Python 3  
**Objetivo:** Aplicar algoritmos y estructuras de datos para resolver problemas de programación competitiva.
